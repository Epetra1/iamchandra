# Chandra Shekhar Dhungana — Portfolio

A responsive static portfolio with an Orbital Studio light/dark theme, animated orbital background, research timeline and age display.

## Download and open

On this GitHub repository, choose **Code → Download ZIP**. Extract the ZIP and open **index.html** in your browser. Keep the **assets/** folder beside the HTML files.

- **index.html** — portfolio, work, education, projects and contact section.
- **thesis.html** — research details, verified results graph and table, and full thesis PDF.
- **assets/** — local styles, JavaScript, logos and thesis PDF. No build or installation required.

## Host on GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/ (root)**, and save. GitHub will display the live website address once deployment finishes. Pushing these files alone does not enable Pages.

## Contact form and outstanding content

The contact form is disabled until a delivery service with server-side spam protection is configured. It never reports a false successful submission. See **READ-ME.txt** for setup, unconfirmed timeline years and remaining logo assets. Employer and university logos are bundled in assets; sources are listed in assets/LOGO-SOURCES.txt.

## Editing

Edit content in the HTML files, theme variables in **assets/styles.css**, interface/age behavior in **assets/site.js**, and orbital animation in **assets/background.js**.
