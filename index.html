2022–2024 Projects

Natural Language Processing and Computer Vision

Implemented speech recognition and face detection in Python, exploring performance under different audio and lighting conditions.

View full project

1. Natural Language Processing and Computer Vision Problem Sets: https://drive.google.com/drive/folders/1Ue8qnghkkoaiQyvmIVMZcA1LRDP1FXZn?usp=drive_link

This project was the final assessment for the Application of Artificial Intelligence (AAI202) course. It involved implementing speech recognition and face detection using Python. The Google Speech Recognition API was used to convert spoken language into text, while the Haar Cascade Classifier identified faces in video frames. Testing showed high accuracy in controlled environments but faced challenges with noise and low light, highlighting areas for improvement.

Exploring MLaaS, BigML and Edge Impulse

Explored TinyML digit recognition, music-preference classification with BigML and knife detection using Edge Impulse.

View full project

2. Exploring MLaaS, BigML, and Edge Impulse for AI-Driven Predictions: https://drive.google.com/drive/folders/1Zw0yWDZRpRMBWHrkY9YLiBxBuYZ8Fo6B?usp=drive_link

In this journey: I conducted research on implementing machine learning for handwritten digit recognition using TinyML. This study explores the use of TensorFlow Lite and the MNIST dataset to develop an optimized model for deployment on resource-constrained devices like the Raspberry Pi Pico.

I researched Machine Learning as a Service (MLaaS) using the BigML platform. I explored the entire machine learning pipeline, from data preprocessing to model evaluation, focusing on a classification task to predict user preferences for music tracks.

I developed a knife detection model using Edge Impulse.
